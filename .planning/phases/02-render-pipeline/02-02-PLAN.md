    **Compositor:**
    Create `src/components/canvas/Compositor.tsx` — the core A/B render target compositor.
    - `'use client'` component
    - Uses `useThree()` to get `gl` (WebGLRenderer), `size`, `camera`
    - Creates two `WebGLRenderTarget` instances (rtA, rtB) — memoized on `size`, using HalfFloatType, LinearFilter, LinearSRGBColorSpace, depthBuffer:true, stencilBuffer:false
    - On size change, call `rt.setSize(size.width, size.height)` to prevent stale render targets (Pitfall 4 from research)
    - Creates a fullscreen quad scene: `THREE.Scene` with `THREE.Mesh(PlaneGeometry(2,2), compositorMaterial)` and `THREE.OrthographicCamera(-1,1,1,-1,0,1)`
    - `compositorMaterial` created via `createCompositorMaterial()` from Plan 01
    - `useFrame` with `renderPriority=1` (takes over R3F auto-render):
      1. Read `eraStore.getState()` for currentEra and eraProgress
      2. Call `getScenePair(currentEra, eraProgress)` to get fromEra, toEra, blend
      3. Call `getMemoryPlan(currentEra, renderBudget.keepAliveWindow, loadedErasRef)` for visibility decisions
      4. Set `visible=true` on eras in memoryPlan.visible, `visible=false` on others
      5. Render fromEra's scene to rtA: `gl.setRenderTarget(rtA); gl.render(sceneRefs[fromEra], camera);`
      6. Render toEra's scene to rtB: `gl.setRenderTarget(rtB); gl.render(sceneRefs[toEra], camera);`
      7. Set blend uniform: `compositorMaterial.uniforms.uBlend.value = blend`
      8. Render composite to screen: `gl.setRenderTarget(null); gl.render(quadScene, orthoCamera);`
    - For preload/dispose from memoryPlan: track loaded eras in a `Set<number>` ref. Call dispose helper on eras in `dispose` list (traverse mesh, geometry.dispose, material.dispose, texture.dispose + ImageBitmap close). Mark preloaded eras as they load.
    - Receive era scene refs via props or context — each era component should expose its underlying THREE.Scene via `useImperativeHandle` or by rendering into a `createPortal` scene
    - Use `createPortal` from R3F for each era scene so they live in separate THREE.Scene instances that the compositor can render independently. Each era renders into its own portal scene.
    - Dispose render targets on unmount (app teardown)
    - IMPORTANT: Do NOT allocate new objects inside useFrame (no `new THREE.Vector3()` etc.) — declare outside and mutate
