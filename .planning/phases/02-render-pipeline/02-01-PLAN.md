       - `dispose`: loaded eras that are outside the visible window (only if loadedEras provided)

    1. Create `src/shaders/dissolve.vert.glsl` — simple fullscreen quad vertex shader: pass through position and UV (`varying vec2 vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);`)

    2. Create `src/shaders/dissolve.frag.glsl` — Perlin noise dissolve fragment shader per research:
       - Uniforms: `tFrom` (sampler2D), `tTo` (sampler2D), `uBlend` (float 0-1), `uNoiseScale` (float, default 2.0), `uEdgeWidth` (float, default 0.08)
       - Include classic 3D Perlin noise (cnoise) from Patricio Gonzalez Vivo's GLSL gist (MIT-compatible)
       - Sample noise at `vec3(vUv * uNoiseScale, uBlend * 0.5)` for organic motion
       - Threshold logic: `smoothstep(threshold - uEdgeWidth, threshold, noise)` for soft dissolve edge
       - Output: `mix(colorFrom, colorTo, edge)` — NOT alpha blending, hard mix based on noise threshold
       - Use organic Perlin noise (not Voronoi) per context — organic noise matches the womb-birth metaphor

    3. Create `src/shaders/womb.vert.glsl` — same fullscreen quad vertex shader as dissolve

    4. Create `src/shaders/womb.frag.glsl` — womb heartbeat pulse:
       - Uniforms: `uTime` (float, seconds), `uBeatRate` (float, default 1.167 = 70bpm), `uIntensity` (float 0-1), `uBirthProgress` (float 0-1, 0=resting, 1=birth flash)
       - Base color: deep red-black `vec3(0.08, 0.01, 0.01)`
       - Pulse color: warm red `vec3(0.4, 0.05, 0.02)`
       - Heartbeat: `pow(sin(uTime * uBeatRate * 6.2832) * 0.5 + 0.5, 3.0)` for sharp pulse shape
       - When uBirthProgress > 0: beat rate accelerates (`uBeatRate * (1.0 + uBirthProgress * 3.0)`), intensity grows, and at uBirthProgress approaching 1.0 the screen floods white-warm
       - No text, no progress indicators — pure visual pulse
       - Subtle vignette (darken edges) for womb-like enclosure feeling

    5. Create `src/components/canvas/CompositorMaterial.ts`:
       - Import GLSL files as raw strings (configure Next.js for raw .glsl imports via next.config if needed)

       - Uniforms object: `{ tFrom: { value: null }, tTo: { value: null }, uBlend: { value: 0 }, uNoiseScale: { value: 2.0 }, uEdgeWidth: { value: 0.08 } }`
       - Set `depthTest: false`, `depthWrite: false` (fullscreen quad)
